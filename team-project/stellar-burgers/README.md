# Stellar Burgers — Team Testing Project

**Project type:** team training project  
**Focus:** collaborative test planning, requirements analysis, execution, defect reporting, and release recommendation

## Scope

The team tested a web product with emphasis on critical user journeys, authentication-related flows, constructor behaviour, orders, navigation, and UI consistency.

## Team workflow

1. Decomposed requirements and mapped product areas.
2. Identified grey zones and questions requiring clarification.
3. Built a shared checklist and distributed execution scope.
4. Logged reproducible defects using a common template.
5. Consolidated results into a test summary.
6. Assessed residual risk and formulated a release recommendation.

## Scale of testing

The shared execution report contained **824 checks** across the team scope. This number represents team coverage, not individual-only work.

## Artifacts used

- shared checklist;
- bug-report register;
- requirements grey-zone table;
- mind map;
- state-transition diagram;
- final test report.

## Release-oriented reporting

The report included:

- environment and tested build;
- planned versus executed coverage;
- passed, failed, and blocked checks;
- defect distribution by severity;
- unresolved risks;
- recommendation on whether release was acceptable and under what limitations.

## My contribution

- participated in requirements analysis and coverage design;
- executed assigned checks;
- documented defects and actual results;
- contributed to team consolidation and discussion of release risk.

## What this demonstrates

- ability to work with shared documentation;
- consistent defect-writing standards;
- communication of dependencies and blockers;
- understanding that testing ends with a risk-based conclusion, not only a bug list;
- transparent separation of individual and team achievements.
