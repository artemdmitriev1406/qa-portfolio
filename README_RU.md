# QA-портфолио — Артём Дмитриев

Портфолио по ручному тестированию: **web, Android, API, анализ требований, тест-дизайн, баг-репорты и ретест**.

Материалы отобраны и переработаны из учебных проектов программы **«Инженер по тестированию» Яндекс Практикума**. Цель репозитория — не выложить все таблицы подряд, а показать подход к анализу требований, проектированию проверок, локализации дефектов и оценке рисков релиза.

## Основные навыки

- функциональное, регрессионное, smoke, исследовательское, UI и мобильное тестирование;
- анализ требований и поиск серых зон;
- чек-листы, тест-кейсы, баг-репорты, ретест и отчёты;
- классы эквивалентности, граничные значения, таблицы решений, pairwise и переходы состояний;
- тестирование REST API и XML/JSON;
- Chrome DevTools, Postman, Swagger, cURL, SQL, Android Studio, ADB, Logcat, Charles Proxy и Figma.
